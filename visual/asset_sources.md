# Suggested external images (download + place into visual/ or Assets/)

This Overleaf environment can't automatically download binary image files from the internet.

If you want external figures (from Wikipedia / Wikimedia Commons), download them locally (prefer SVG/PNG) and upload them into this project, then reference them from the LaTeX paper.
